# Licences et crédits

Le manifeste Composer historique déclare `MIT` pour le squelette Laravel. Aucun nouveau choix de licence pour l’ensemble du code métier n’est ajouté par cette préparation ; confirmer les droits et la licence du projet avant une redistribution publique. Les dépendances conservent leurs licences propres, décrites dans les fichiers de verrouillage et leurs distributions.

Les 12 photos illustratives de véhicules proviennent de Wikimedia Commons, sous CC0 selon les pages source consultées. Le manifeste [vehicles.json](application/resources/demo/vehicles.json) conserve modèle, auteur, page source, licence, URL d’origine, taille et empreinte SHA256. La liste lisible est dans [credits.html](application/public/demo/vehicles/credits.html). Les fichiers téléchargés sont inclus sans retouche dans `application/public/demo/vehicles/`.

Les captures de démonstration utilisent ces mêmes illustrations et des données fictives. La carte OpenStreetMap est optionnelle dans l’application ; ses données et tuiles conservent leurs conditions et attributions. Consulter [la politique des tuiles](https://operations.osmfoundation.org/policies/tiles/) avant un usage réel. La capture GPS conserve l’attribution cartographique visible.
